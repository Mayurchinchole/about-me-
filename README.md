## 🚀 Featured Project

### 🌍 Worldwide Earthquake Events – Microsoft Fabric

A Data Engineering project using the USGS Earthquake API and Medallion Architecture.

- 🥉 **Bronze Layer:** Ingesting raw earthquake JSON data.
- 🥈 **Silver Layer:** Data cleaning and transformation using PySpark.
- 🥇 **Gold Layer:** Enriched and analytics-ready earthquake data.
- ⚙️ **Architecture:** Bronze → Silver → Gold.

**Technologies:** Microsoft Fabric, PySpark, Python, API, Delta Lake.
